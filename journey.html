Journey / engineering path

From full-stack foundations to AI systems.

The through-line is practical: learn the minimum theory needed to build, debug, optimize and explain real systems.

2024–25

Computer science + software foundations

Programming, databases, data structures, Linux, web development and security practice formed the base layer.

2025–26

Applied ML + security automation

Projects moved into scikit-learn workflows, classification/forecasting, reconnaissance tooling and hands-on security labs.

2026

GenAI systems

RAG, local LLMs, FastAPI, Ollama, prompt architecture and agent-oriented workflows became a central engineering focus.

2026 →

Deep learning + production AI

Current work is moving through PyTorch and neural networks toward transformers, embeddings, fine-tuning, inference, evaluation and deployment.
