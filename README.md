# Portfolio

This is a static HTML, CSS, and JavaScript portfolio for Paladugu Ganesh Naidu.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

Example with VS Code Live Server:

1. Open the project folder.
2. Start Live Server on `index.html`.

Example with Node:

```bash
npx serve .
```

## Edit content

All portfolio content currently lives in `index.html` so it is easy to update without a build step.

Main files:

- `index.html`: content and structure
- `css/style.css`: theme, layout, responsive design, and animations
- `js/main.js`: menu behavior, scroll progress, reveal animations, active nav state, and back-to-top

## Design direction

- Palette: warm ivory background with pastel pink, dusty blue, sage green, and terracotta accents
- Style: airy cards, soft shadows, rounded surfaces, and semi-transparent layers
- Motion: scroll reveals, hero typewriter, parallax hover accents, progress indicator, and smooth menu transitions
